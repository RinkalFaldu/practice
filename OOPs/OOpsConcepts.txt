Getters & setters
Get : to return the value
Set : to modify the value

this : this keyword is used to refer to the current object
Constructors: Constructors is a special methods which is invoked automatically at the time of object creation
- Constructors have the same name as class or structure.
- Constructors don't have a return type. (Not even void)
- Constructors are only called once, at object creation
- Memory allocation happens when constructor is called.

Types of Constructors
Non-parameterized
parameterized
Copy Constructor : copy constructor transfer properties of object one into second object

Constructor ovrloading (polymorphisum) : when we create multiple constructors with different parameter. when we create new object appropriate constructor will be called
Number of parameters: For example, one constructor with no arguments and another with two.
Data types of parameters: For example, one using an int and another using a String.
Order of parameters: For example, (int, String) versus (String, int) 

Encapsulation : encapsulation is defined as the wrapping up of data & methods under a single unit. it also implements data hiding. e.g. class 

shallow & Deep Copy :
Shallow : it copy reference , and reflect changes , copied object pointing to the original object
Deep : changes do not reflect , it create new copy of new object 

Destructors : garbage collector work as Destructors we don't need to write Destructors

Inheritance: is when properties & methods of base class (parent class) are passed on to a derived class (child class). 

Types of Inheritance:
Single level Inheritance:   Base class ----> Derived class
Multi Level Inheritance:  Base class ----> Derived class -----> derived class
Hierarchial Inheritance: Base class 
                          /       \
                         /         \
                        /           \
                    Derived class    Derived class

Hybrid Inheritance: Base class 
                     /       \
                    /         \
                   /           \
            Derived class    Derived class
                                |
                                |
                                |
                                |
                         Derived class
Multiple Inheritance: (in c++)

polymorphisum:  poly means many and morphism means forms

Types of polymorphisum
Compile Time polymorphisum: Method overloading 
Run Time polymorphisum: Method overriding

Method overloading : Multiple functions with the same name but different parameters
Method overriding: Parent and child classes both contain the same function with a different definition

Packages in java: package is a group of similar types of classes, interfaces and sub-Packages
Types of packages 
In built : e.g. util package
User defined: writing package name on top of file to make that file of package
